**✅ Boilerplate completo gerado!** 🚀

Criei a estrutura inicial completa do **gsi_ebd** no ambiente sandbox. Você pode copiar tudo para o seu repositório GitHub.

### Como baixar e usar agora:

```bash
cd /caminho/do/seu/projeto
# Copie o conteúdo (ou baixe o zip se preferir)
# Depois rode:
uv venv
uv pip install -r requirements.txt
cp .env.example .env
reflex init
reflex db init
reflex run
```

### Arquivos criados (estrutura principal):

- **`rxconfig.py`** → Config com Postgres
- **`requirements.txt`** → Dependências iniciais
- **`docker-compose.yml`** → Postgres + App (seu estilo)
- **`gsi_ebd/models/`** → User (com Role + hierarquia), Study, StudyVersion, Assignment, Progress
- **`gsi_ebd/states/auth.py`** → AuthState estendido com reflex-local-auth + redirecionamento por role
- **`gsi_ebd/pages/`** → Login + Dashboards básicos por perfil (Admin, Gestor, Aluno)
- **`gsi_ebd/main.py`** → App principal com rotas
- **`README.md`** → Instruções
- Diretórios prontos: `ai/`, `services/`, `utils/`, `data/lessons/`, `components/`
